# FreeCut AI

Fast browser-first AI-style video generator.

## Features
- Prompt to automatic scenes
- 9:16 Shorts/Reels, 16:9 YouTube, 1:1
- 15/30/60 second generation
- Animated visuals
- Browser text-to-speech
- Scene captions
- Downloadable WebM
- No API key required

## GitHub Pages
Repository Settings → Pages → Deploy from branch → main → /(root).

## Note
This starter intentionally runs client-side. It does not call a paid generative-video API. True AI image/video providers can be added later behind a server-side API so keys remain private.
